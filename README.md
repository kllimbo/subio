# Подписки

Личное приложение для учёта подписок. Сейчас это устанавливаемая веб-версия; отдельный iPhone-пакет пока не собирается.

## Что уже работает

- Подписки и настройки сохраняются в браузере на устройстве.
- Список можно использовать без интернета после первой загрузки: оболочка приложения кэшируется.
- Курс USD/RUB загружается при подключении к интернету примерно раз в сутки. Последний курс и дата сохраняются локально.
- Если курса ещё нет, смешанная сумма в разных валютах не показывается как точная.
- Автоматический перенос даты обновляет только расписание. Пробные подписки и отменённые записи архивируются после даты окончания.
- Резервную копию списка и настроек можно экспортировать в JSON и восстановить через импорт.

## Как открыть на компьютере

В PowerShell из этой папки выполни:

```powershell
node preview-server.js
```

Затем открой `http://127.0.0.1:4173/`.

## Как открыть на iPhone

Safari позволяет добавить сайт на главный экран как веб-приложение. Для работы офлайн-кэша через Service Worker и для Web Push нужен HTTPS. Локальный адрес `127.0.0.1` доступен только на компьютере, поэтому следующий инфраструктурный шаг — разместить эти статические файлы на HTTPS-хостинге, затем открыть ссылку в Safari и выбрать «На экран Домой».

## Что ещё не подключено

- Системные уведомления о подписках. Для веб-приложения на iPhone нужны Web Push и сервер отправки; локальные уведомления потребуют нативной iOS-версии.
- Виджет iPhone. Его можно добавить только в нативной версии.
- Отдельная сборка iOS-приложения и синхронизация между устройствами.

Данные подписок не отправляются на сервер приложения. Для курса используется внешний API; на главном экране есть ссылка на его источник.
